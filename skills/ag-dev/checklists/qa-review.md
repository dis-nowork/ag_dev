# QA Review Checklist

## Test Gate
- [ ] [blocker] All tests pass
- [ ] [required] No critical security issues
- [ ] [required] Code follows project conventions
- [ ] [optional] Performance acceptable
- [ ] [optional] Edge cases covered

## Acceptance Gate
- [ ] [blocker] Output file contains DONE marker
- [ ] [required] No regressions introduced
- [ ] [required] Changes match original task description
- [ ] [optional] Code review comments addressed
