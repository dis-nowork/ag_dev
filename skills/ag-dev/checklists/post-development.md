# Post-Development Checklist

## Implementation Gate
- [ ] [blocker] All files from architecture exist
- [ ] [blocker] No syntax errors (build passes)
- [ ] [required] Tests exist for new code
- [ ] [required] No hardcoded secrets
- [ ] [required] Output file written to handoff directory
- [ ] [optional] Documentation updated

## Code Quality Gate
- [ ] [required] No TODO/FIXME/HACK without ticket reference
- [ ] [required] Conventional commits used
- [ ] [optional] Linter passes
- [ ] [optional] Type checks pass
